## Cotizador, estimador y precisador de Pi
Este repositorio contiene:
- Un programa para calcular el saldo de un préstamo en interés compuesto, según la calificación de su cliente.
- Un programa para estimar $\pi$ con el método Monte Carlo según la iteración del método.
- Un programa para estimar $\pi$ con el método Monte Carlo con un margen de error.
